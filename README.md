`Neural Networks Playground` — это коллекция Jupyter Notebook, демонстрирующих применение нейронных сетей для решения различных задач машинного обучения: классификация изображений (MNIST, CIFAR-10) и прогнозирование временных рядов (температура). Проект включает примеры использования PyTorch и TensorFlow, а также базовые операции с тензорами и визуализацию результатов.

## Описание

Проект представляет собой набор экспериментов с нейронными сетями, реализованных в Jupyter Notebook. Он охватывает:
1. **Классификацию изображений**:
   - Простая полносвязная сеть для MNIST (PyTorch).
   - Сверточная нейронная сеть (CNN) для CIFAR-10 (TensorFlow).
2. **Прогнозирование временных рядов**:
   - Рекуррентная сеть LSTM для предсказания температуры на основе исторических данных (PyTorch).
3. **Операции с тензорами**:
   - Примеры использования функций PyTorch (`torch.cat`, `torch.gather`, и др.).

Каждый ноутбук включает загрузку данных, обучение модели, тестирование и визуализацию результатов.

## Функциональность

### 1. MNIST Classifier (PyTorch)
- **Цель**: Классификация рукописных цифр (0–9).
- **Модель**: Полносвязная сеть с одним скрытым слоем (128 нейронов).
- **Данные**: Датасет MNIST.
- **Результат**: Предсказание цифры на пользовательском изображении.

### 2. Tensor Operations (PyTorch)
- **Цель**: Демонстрация базовых операций с тензорами.
- **Функции**: `torch.cat`, `torch.gather`, `torch.index_select`, `torch.narrow`, `torch.nonzero`, `torch.reshape`.
- **Результат**: Примеры вывода для каждой операции.

### 3. Weather Predictor (PyTorch)
- **Цель**: Прогнозирование максимальной и минимальной температуры.
- **Модель**: LSTM с одним скрытым слоем (100 нейронов).
- **Данные**: Исторические данные о погоде (2010–2021).
- **Результат**: График предсказанных и фактических значений температуры.

### 4. CIFAR-10 Classifier (TensorFlow)
- **Цель**: Классификация изображений из 10 классов (самолёты, машины и др.).
- **Модель**: Сверточная сеть (3 слоя Conv2D + 2 полносвязных).
- **Данные**: Датасет CIFAR-10.
- **Результат**: Графики точности и потерь на обучении и валидации.

## Установка

### Требования
- Python 3.10+
- PyTorch 2.2.1+cu121
- TensorFlow 2.x
- Библиотеки: `torchvision`, `pandas`, `scikit-learn`, `matplotlib`, `numpy`

Установка зависимостей:
```bash
pip install torch torchvision tensorflow pandas scikit-learn matplotlib numpy
```

Для работы в Google Colab установка не требуется — все зависимости уже присутствуют.

### Клонирование репозитория
```bash
git clone https://github.com/yourusername/neural-networks-playground.git
cd neural-networks-playground
```

## Использование

1. **Запуск в Jupyter Notebook**:
   - Установите Jupyter:
     ```bash
     pip install jupyter
     ```
   - Запустите Jupyter:
     ```bash
     jupyter notebook
     ```
   - Откройте нужный `.ipynb` файл (например, `2.ipynb` для MNIST).

2. **Запуск в Google Colab**:
   - Загрузите `.ipynb` файлы в Colab через интерфейс.
   - Выполните ячейки последовательно.
